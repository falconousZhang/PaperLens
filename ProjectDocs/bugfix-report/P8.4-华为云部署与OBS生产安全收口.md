# P8.4 华为云部署与 OBS 生产安全收口

## 问题与根因

码道初版完成了主要文件，但生产链路存在会阻断部署或削弱边界的缺陷：OBS ECS 认证、超时和 header 使用了错误 SDK 契约；下载路径生命周期失效且 delete 未检查状态；生产配置允许弱 JWT、非验证型 RDS TLS、mock 模型和宽泛端点；ReDoc 仍暴露。迁移容器绕过 entrypoint，数据库口令进入环境，前端 Dockerfile 无法从原构建上下文复制 Nginx，非 root Nginx 又会写只读 pid/temp 路径。Compose 镜像占位符、端口、代理链和部署文档也不一致。

## 修正结果

- 按 OBS SDK 当前契约实现 ECS Agency、TLS、私有加密 header、2xx 检查和临时文件清理。
- 生产 Settings 对华为端点、RDS verify-full/CA、强 JWT、真实 MaaS/Embedding 和代理网段 fail-closed。
- serve/migrate 统一通过 Secret 文件入口，DSN 与 API Key 不进入 Compose 明文环境。
- 后端使用 Python 3.13 生产依赖；前端修正 root context、非 root 8080、`/tmp` pid/temp 和只读启动。
- Compose 固定私网，仅发布前端端口，使用资源限制、ready/healthz、不可变镜像变量和 RDS CA Secret。
- 部署与恢复文档删除未经验证的固定 RPO/RTO，明确真实云验收仍需用户执行。

## 验证

P8.4 定向 3 passed；后端与前端生产镜像构建成功。后端以 `paperlens` 非 root、只读根文件系统启动并返回 live 200、docs 404，镜像不含 pytest/tests；前端以 `nginx` 非 root、只读、cap_drop ALL 启动并返回 healthz 和首页。Compose 在未替换 IP 占位符时拒绝解析，显式假值时静态校验通过。未访问真实 RDS、OBS、MaaS，未修改开发库或现有项目容器。
