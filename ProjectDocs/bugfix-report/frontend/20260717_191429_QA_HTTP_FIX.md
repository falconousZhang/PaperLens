# 公网 HTTP 论文问答首轮提交失败修复报告

**报告 ID**：20260717_191429  
**修复类型**：frontend  
**严重程度**：major  
**处理方**：CodeArts（码道）  
**日期**：2026-07-17

## 问题描述

公网 HTTP 部署中，用户发送首个问题后页面立即提示“网络连接失败”，新建的空会话随后被删除，后端没有收到首轮问题请求。

## 根因

前端直接调用 `crypto.randomUUID()` 生成请求幂等键。该接口只在安全上下文中保证可用，当前 ECS 使用普通 HTTP，浏览器在真正发起首轮请求前抛出本地异常。统一异常处理又把该本地错误误判为网络故障。

## 修复方案

- 增加 UUID v4 兼容生成器：优先使用 `randomUUID`，不可用时回退到 `getRandomValues`。
- 只有异常包含实际网络请求对象时才显示网络连接失败，本地运行异常显示对应业务失败提示。
- 增加非安全上下文下创建并提交首轮问答的定向用例。
