## 1. 模块概述

论文上传与解析模块负责 PDF 文件的上传、校验、存储和结构化解析，是 PaperLens 系统的入口模块。用户上传 PDF 后，系统自动触发后台解析任务，提取页面文本、章节结构、表格数据，并生成文本分块。

## 2. 后端设计

### 2.1 论文上传服务

**核心流程:**

1. 接收 multipart/form-data 上传请求
2. 文件校验（类型、大小、路径穿越）
3. 计算 SHA-256 文件哈希
4. 存储原始 PDF（StorageBackend）
5. 创建 Paper 记录（当前直接设为 PROCESSING；UPLOADING 枚举值未在此路径使用）
6. 注册后台解析任务

**关键实现:**

- 文件类型校验: 检查扩展名 + PDF magic bytes
- 路径穿越防护: `sanitize_filename()` 清洗文件名为 basename
- 资源清理: 上传失败时回滚存储和临时文件
- SHA-256 哈希: 已计算并存储到 `file_hash` 字段，但去重/复用逻辑尚未实现（📋 PLANNED）
- 上传接口: 仅接受 `file` 字段，无可选 `title`；标题 = 清洗后的文件名 stem；响应状态 = `PROCESSING`
- 认证: `_get_user_id()` 返回 `settings.demo_user_id`，无 Bearer/JWT 鉴权（📋 PLANNED）

**API 接口:**

| 接口 | 方法 | 路径 | 状态 | 说明 |
|------|------|------|------|------|
| 上传论文 | POST | /api/v1/papers/upload | ✅ CURRENT | 仅 file 字段，title=文件名stem，status=PROCESSING |
| 获取论文列表 | GET | /api/v1/papers | ✅ CURRENT | 分页查询，支持 status 过滤 |
| 获取论文详情 | GET | /api/v1/papers/{paper_id} | ✅ CURRENT | 含 error_message |
| 删除论文 | DELETE | /api/v1/papers/{paper_id} | 📋 PLANNED | 级联删除所有关联数据 |

### 2.2 PDF 解析服务

**核心流程:**

1. 使用 PyMuPDF 提取页面文本和尺寸
2. 生成 normalized_text_content（空白字符合并）
3. 识别章节结构（正则匹配标题模式）
4. 使用 pdfplumber 提取表格
5. 文本分块（按章节/段落）
6. 提取 Evidence（page-local, PyMuPDF block）

**关键实现:**

- 双引擎解析: PyMuPDF（文本/页面）+ pdfplumber（表格）
- normalized_text_content: 合并连续空白字符，用于前端高亮定位
- 章节识别: 正则匹配 ABSTRACT / INTRODUCTION / METHOD 等关键词
- 表格降级: 非法表格（page_number=0）使用 SAVEPOINT 跳过，不影响整体解析
- Evidence 提取: 基于 PyMuPDF block，page-local 定位，真实 bbox 坐标

**数据模型:**

| 表名 | 说明 |
|------|------|
| papers | 论文主表（id, title, filename, storage_key, file_hash, status） |
| paper_pages | 页面表（text_content, normalized_text_content, width, height） |
| paper_sections | 章节表（section_type, title, level, sequence, start_page, end_page） |
| paper_chunks | 文本分块表（chunk_index, content, char_count, page_numbers, embedding_id） |
| paper_tables | 表格表（page_number, table_index, caption, bbox, structured_data, raw_text） |
| evidences | 证据表（quoted_text, page_number, bbox, char_start, char_end, evidence_type） |

## 3. 前端设计

### 3.1 论文上传页面 (P02 UploadView)

**核心功能:**

- 拖拽/选择 PDF 文件上传
- 文件类型和大小校验
- 上传进度显示
- 上传成功跳转到论文详情

**交互行为:**

| 交互 | 行为 |
|------|------|
| 拖拽文件进入 | 拖拽区边框变深色，背景变浅紫 |
| 选择/拖拽文件 | 校验文件类型（.pdf）和大小（<=50MB） |
| 点击"上传" | 调用 POST /api/v1/papers/upload，显示进度条 |
| 上传成功 | 路由跳转至 /papers/:id |
| 上传失败 | 显示错误信息，保留文件选择状态 |

### 3.2 论文列表页面 (P03 PaperListView)

**核心功能:**

- 论文表格列表，含标题、文件名、状态、页数、创建时间
- 状态标签颜色区分（解析中/已解析/失败/上传中）
- PROCESSING 状态自动轮询（3 秒间隔）
- 分页支持

**交互行为:**

| 交互 | 行为 |
|------|------|
| 页面加载 | 调用 GET /api/v1/papers |
| 存在 PROCESSING | 启动 3 秒间隔轮询 |
| 点击"查看" | 路由跳转至 /papers/:id |
| 组件卸载 | 清除轮询定时器 |

### 3.3 论文详情页面 (P04 PaperDetailView)

**核心功能:**

- 三 Tab 切换：章节 / 页面 / 证据
- 章节 Tab：章节卡片列表
- 页面 Tab：页面文本展示 + Evidence 高亮
- 证据 Tab：证据列表，点击跳转高亮

**Evidence 高亮机制:**

- 基于 char_start / char_end 在 normalized_text_content 中标记
- 高亮后自动 scrollIntoView
- char 区间无效时显示降级提示

## 4. 关键设计决策

| 决策 | 说明 |
|------|------|
| 双引擎解析 | PyMuPDF 文本提取准确，pdfplumber 表格提取能力强，互补使用 |
| normalized_text_content | 前端高亮需要稳定的字符偏移，空白字符合并提供一致性 |
| SAVEPOINT 降级 | 非法表格不影响论文整体解析，保证健壮性 |
| page-local Evidence | PyMuPDF block 天然页内，bbox 坐标准确，实现简单 |
