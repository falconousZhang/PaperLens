## 1. 模块概述

审阅生成模块负责基于论文内容和 Evidence 生成结构化审阅结果。每条 ReviewFinding 必须关联至少一个 Evidence，未关联 Evidence 的 Finding 标记为 UNVERIFIED，不展示给用户。

## 2. 后端设计

### 2.1 审阅生成服务

**核心流程:**

1. 根据审阅维度构造检索 query
2. 在 FAISS 向量索引中检索 Top-K 相关 PaperChunk
3. 将 Prompt + Evidence 传入 LLM
4. LLM 返回审阅结果（含 Evidence ID 标注）
5. 后处理验证：每条 Finding 必须关联至少一个 Evidence
6. 写入 ReviewResult + ReviewFinding + Evidence 绑定
7. 未关联 Evidence 的 Finding 标记为 UNVERIFIED，不展示

**关键设计:**

- 审阅维度: SOUNDNESS / NOVELTY / CLARITY / COMPLETENESS / REPRODUCIBILITY / SIGNIFICANCE / OVERALL
- Finding 类型: STRENGTH / WEAKNESS / SUGGESTION
- 评分: 1-5 整数
- overall_verdict: ACCEPT / WEAK_ACCEPT / BORDERLINE / WEAK_REJECT / REJECT
- Evidence 绑定: 通过 finding_evidence 关联表实现多对多关系
- UNVERIFIED 过滤: verification_status=UNVERIFIED 的 Finding 不返回给前端

**API 接口:**

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 创建审阅任务 | POST | /api/v1/papers/{paper_id}/tasks | task_type=REVIEW |
| 获取审阅结果 | GET | /api/v1/papers/{paper_id}/reviews | 含 Evidence 的结构化结果 |
| 获取任务详情 | GET | /api/v1/tasks/{task_id} | 轮询任务进度 |
| 取消任务 | POST | /api/v1/tasks/{task_id}/cancel | 取消审阅任务 |

**数据模型:**

| 表名 | 说明 |
|------|------|
| analysis_tasks | 分析任务表（task_type=REVIEW, status, progress） |
| review_results | 审阅结果表（dimension, rating, summary, overall_verdict） |
| review_findings | 审阅发现表（finding_type, content, confidence, verification_status） |
| finding_evidence | 发现-证据关联表（finding_id, evidence_id） |

### 2.2 LLM Prompt 设计

**Prompt 结构:**

```
System: 你是一位学术论文审阅专家。请基于提供的论文内容生成结构化审阅意见。

User:
论文标题: {title}
审阅维度: {dimension}
相关 Evidence:
- [E1] {evidence_1}
- [E2] {evidence_2}
...

请按以下格式输出:
- Finding 类型: STRENGTH / WEAKNESS / SUGGESTION
- 内容: [审阅意见]
- 关联 Evidence ID: [E1, E2, ...]
- 置信度: 0.0-1.0
```

**关键约束:**

- LLM 必须通过统一 LLMClient 接口调用
- MockLLMClient 返回固定结构化响应，用于开发测试
- LLM 输出需后处理验证，确保 Finding 关联 Evidence

## 3. 前端设计

### 3.1 审阅结果页面 (P05 ReviewResultView)

**核心功能:**

- 审阅概览：总评分数、维度数、Finding 总数
- 维度卡片：按 dimension 分组，每个维度显示评分和摘要
- Finding 卡片：类型标签（STRENGTH 绿 / WEAKNESS 红 / SUGGESTION 蓝）、内容、置信度
- 证据链接：点击跳转到页面 Tab 高亮对应 Evidence
- 空状态：未发起审阅时显示"发起审阅"按钮
- Finding 类型筛选

**交互行为:**

| 交互 | 行为 |
|------|------|
| 页面加载 | 调用 GET /papers/:id/reviews |
| 点击"查看证据" | 切换到页面 Tab，跳转到 Evidence 所在页并高亮 |
| 无审阅结果 | 显示"发起审阅"按钮，调用 POST /papers/:id/tasks |
| 审阅进行中 | 显示进度条，3 秒轮询任务状态 |

## 4. 关键设计决策

| 决策 | 说明 |
|------|------|
| Evidence 强制绑定 | 消除 LLM 幻觉，每条 Finding 必须有原文依据 |
| UNVERIFIED 过滤 | 未关联 Evidence 的 Finding 不展示，保证可信度 |
| MockLLMClient | 开发测试无需云端密钥，返回固定结构化响应 |
