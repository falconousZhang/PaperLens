## 1. 模块概述

本模块将已解析论文的 Evidence 转换为可追溯的结构化审阅结果。P3.1 已实现任务创建、后台执行、严格 JSON 解析、ReviewResult/ReviewFinding 持久化、Evidence 绑定和结果查询。每条公开 Finding 必须完整引用本次候选 Evidence；无法完整绑定的 Finding 标记为 UNVERIFIED 并从公开响应中过滤。

## 2. P3.1 当前后端设计

### 2.1 审阅生成服务

当前流程：

1. 仅允许当前 `DEMO_USER_ID` 对状态为 PARSED 且含 Evidence 的论文创建 REVIEW 任务。
2. Evidence 按 `page_number ASC, created_at ASC, id ASC` 稳定排序，默认选择前 8 条。
3. 为候选建立临时别名 E1、E2……；Prompt 不暴露或信任模型自行生成的数据库 UUID。
4. 将论文标题、目标维度、语言和转义后的 Evidence 写入带安全边界的 Prompt。
5. 通过统一 LLMClient 调用确定性的 MockLLMClient。
6. 使用 Pydantic 严格解析单个 JSON object，拒绝代码围栏、额外字段、错误类型和不匹配维度。
7. 每条 Finding 的 alias 全部有效时标记 VERIFIED 并写入 finding_evidences；否则整条标记 UNVERIFIED，不做部分绑定。
8. 多维度结果和任务 SUCCEEDED 状态在同一次提交中完成；任一维度失败时回滚本任务全部新结果，再以安全文案写入 FAILED。

P3.1 的候选选择是可复现的开发回退，不是语义检索。FAISS/Embedding 属于 P3.2。

### 2.2 数据契约

审阅维度：

- SOUNDNESS
- NOVELTY
- CLARITY
- COMPLETENESS
- REPRODUCIBILITY
- SIGNIFICANCE
- OVERALL

Finding 类型为 STRENGTH / WEAKNESS / SUGGESTION；rating 为 1～5 严格整数；confidence 为 0～1 JSON 数值。只有 OVERALL 允许且必须返回 overall_verdict，取值为 ACCEPT / WEAK_ACCEPT / BORDERLINE / WEAK_REJECT / REJECT。

### 2.4 LLM Prompt 与严格输出

Prompt 中 Evidence 使用 `<evidence id="E1">` 边界并转义原文中的标签字符，同时明确论文原文是不可信数据。模型必须只返回下列 JSON 结构：

```json
{
  "dimension": "SOUNDNESS",
  "rating": 4,
  "summary": "...",
  "overall_verdict": null,
  "findings": [
    {
      "finding_type": "STRENGTH",
      "content": "...",
      "confidence": 0.9,
      "evidence_refs": ["E1"]
    }
  ]
}
```

MockLLMClient 无需密钥或网络，根据 dimension 和候选 alias 返回确定性内容。P3.3 将新增 HuaweiMaaSLLMClient；Mock 继续作为本地开发与自动测试实现。

### 2.5 数据模型与隔离

| 表名 | 当前用途 |
|------|----------|
| analysis_tasks | REVIEW 任务状态、进度、用户归属与安全错误信息 |
| review_results | 每个任务的维度评分和摘要 |
| review_findings | Finding 内容、置信度与 VERIFIED/UNVERIFIED 状态 |
| finding_evidences | VERIFIED Finding 与同论文 Evidence 的关联 |

任务详情按 AnalysisTask.user_id 隔离；审阅查询同时校验 Paper.user_id，并在 SQL 查询中通过 AnalysisTask.user_id 再次约束结果归属。

## 4. 关键设计决策

| 决策 | 说明 |
|------|------|
| Mock 先行 | 先验证任务、解析、事务和绑定，不让真实模型不确定性掩盖后端缺陷 |
| Evidence 全有或全无绑定 | 混合合法/非法 alias 不做部分关联 |
| UNVERIFIED 过滤 | 保留审计记录，但不向用户展示无可靠依据的 Finding |
| 结果批次原子提交 | 多维度任一失败时不留下部分 ReviewResult |
| 华为云优先、接口可替换 | 生产默认走华为云，Mock 与本地回退保障测试和可移植性 |
