## 1. 模块概述

实验数据分析模块负责上传 CSV/Excel 实验数据文件，解析数据列，使用确定性 Python 代码计算统计摘要，并与论文报告的指标进行交叉验证，标记偏差。

## 2. 后端设计

### 2.1 实验数据上传服务

**核心流程:**

1. 接收 CSV/XLSX/XLS 文件上传（最大 20MB）
2. 文件类型校验和大小限制
3. 使用 pandas 解析数据列
4. 自动识别指标列与条件列
5. 存储 ExperimentFile 记录

**关键设计:**

- 文件类型: CSV / XLSX / XLS
- 文件大小: 最大 20MB
- pandas 解析: 自动识别列类型
- columns_info: JSONB 存储列名与类型信息

**API 接口:**

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 上传实验数据 | POST | /api/v1/papers/{paper_id}/experiment-files/upload | multipart/form-data |
| 获取文件列表 | GET | /api/v1/papers/{paper_id}/experiment-files | 已上传文件列表 |
| 获取分析结果 | GET | /api/v1/experiment-files/{file_id}/result | 统计摘要 + 交叉验证 |
| 删除文件 | DELETE | /api/v1/experiment-files/{file_id} | 删除文件及分析结果 |

**数据模型:**

| 表名 | 说明 |
|------|------|
| experiment_files | 实验数据文件表（filename, storage_key, file_type, row_count, column_count, columns_info） |
| experiment_results | 实验数据分析结果表（summary_stats, column_analysis, metric_comparisons） |

### 2.2 统计摘要计算服务

**核心流程:**

1. 使用 pandas 读取实验数据
2. 对数值列计算统计摘要（count、mean、std、min、max、median）
3. 存储为 summary_stats（JSONB）

**关键约束:**

- **LLM 不参与任何数值计算**，所有统计由确定性 Python 代码完成
- 使用 pandas 内置函数，结果确定性

**summary_stats JSONB 结构:**

```json
{
  "columns": {
    "accuracy": {
      "count": 10,
      "mean": 0.852,
      "std": 0.023,
      "min": 0.810,
      "max": 0.891,
      "median": 0.855
    }
  }
}
```

### 2.3 指标交叉验证服务

**核心流程:**

1. 匹配论文 MetricRecord 与实验数据中的指标
2. 计算偏差值（diff = paper_value - experiment_value）
3. 标记验证状态（MATCH / MISMATCH）

**metric_comparisons JSONB 结构:**

```json
[
  {
    "metric_name": "accuracy",
    "dataset": "SQuAD",
    "paper_value": 0.891,
    "experiment_value": 0.855,
    "diff": -0.036,
    "checkpoint_type": "MAX",
    "status": "MISMATCH"
  }
]
```

## 3. 前端设计

### 3.1 实验数据页面 (P07 ExperimentDataView)

**核心功能:**

- 上传区：拖拽/选择上传 CSV/XLSX/XLS，最大 20MB
- 文件列表：已上传文件表格，含文件名、类型、行列数、删除操作
- 统计摘要：每列的 count/mean/std/min/max/median
- 交叉验证：论文指标 vs 实验数据对比，MATCH(绿)/MISMATCH(红) 状态标签

**交互行为:**

| 交互 | 行为 |
|------|------|
| 上传文件 | 校验类型和大小，调用 POST /papers/:id/experiment-files/upload |
| 上传成功 | 刷新文件列表和统计摘要 |
| 点击"删除" | 确认弹窗，调用 DELETE /experiment-files/:file_id |
| 页面加载 | 调用 GET /papers/:id/experiment-files |
| 选择文件 | 调用 GET /experiment-files/:file_id/result |

## 4. 关键设计决策

| 决策 | 说明 |
|------|------|
| 确定性计算 | LLM 不参与数值计算，保证结果可复现 |
| JSONB 存储 | summary_stats 和 metric_comparisons 使用 JSONB，灵活扩展 |
| MATCH/MISMATCH | 简单二值判断，后续可引入阈值配置 |
