## 1. P5.1 实验数据上传服务

### 1.1 处理流程

1. 将用户文件名规整为不超过 255 code point、无控制字符的 basename，只接受 `.csv`、`.xlsx`、`.xls`。
2. `UploadFile` 按 1MiB 固定块写入随机服务端临时文件，以实际读取字节执行 1～20MB 限制。
3. 在线程池中按已确认类型检查 CSV/ZIP/OLE 容器 magic，计算 SHA-256，再执行确定性结构解析。
4. 解析器只接受临时路径和 `ExperimentFileType`，不持有 Session，不调用 LLM、Embedding 或网络。
5. 按 `(user_id, paper_id, file_hash)` 查询重复；已有资源返回 200，新资源先保存内部对象再写数据库并返回 201。
6. 并发重复由 008 唯一约束收口；失败请求回滚并清理未归属对象。所有路径关闭 UploadFile、删除临时文件。

### 1.2 结构契约

`columns_info` 是 version=1 的稳定 JSON object：

```json
{
  "version": 1,
  "encoding": "utf-8",
  "delimiter": ",",
  "sheet_name": null,
  "columns": [
    {
      "name": "accuracy",
      "dtype": "float",
      "nullable": false,
      "null_count": 0
    }
  ]
}
```

dtype 仅允许 `integer|float|boolean|datetime|string|empty`。对象不保存样本值或数据行；CSV 的 `sheet_name` 为 null，Excel 的 `encoding` 和 `delimiter` 为 null。

### 1.3 解析安全边界

- CSV：UTF-8、UTF-8 BOM、GB18030；分隔符仅逗号、分号、Tab，候选不唯一即拒绝；拒绝 NUL、坏编码、坏引号、行宽不一致、空/仅表头文件。
- XLSX：合法 ZIP 且包含 `[Content_Types].xml` 和 `xl/workbook.xml`；限制 entry 数、单项/总压缩比和总解压大小；拒绝正反斜杠穿越、绝对/盘符路径、重复或加密 entry、宏、外链、嵌入对象、多个非空 sheet 和公式节点。
- XLS：扩展名、OLE magic、xlrd 解析三重校验；仅读取单一非空 worksheet 的缓存值，不执行宏、DDE、外链或网络。
- 数据范围：1～100000 行、1～256 列；列名去 BOM/首尾空白后非空、唯一、无控制字符且最长 128 code point。

### 1.4 存储与事务

PDF key 保持 `papers/{paper_id}/source.pdf`。实验对象使用 `experiment-files/{uuid}/source.csv|source.xlsx|source.xls`，不使用用户路径。`storage.save`、flush、refresh、commit 任一步失败都 rollback 并补偿对象；日志只允许固定阶段、object key 和异常类型。

## 2. P5.1 API

| 状态 | 方法 | 路径 | 说明 |
|------|------|------|------|
| CURRENT | POST | `/api/v1/papers/{paper_id}/experiment-files/upload` | 新建 201，重复 200 |
| CURRENT | GET | `/api/v1/papers/{paper_id}/experiment-files` | page/page_size 分页，稳定倒序 |
| CURRENT | GET | `/api/v1/experiment-files/{file_id}` | 严格结构元数据详情 |
| CURRENT | POST | `/api/v1/experiment-files/{file_id}/analysis` | 新建 201；幂等 200 |
| CURRENT | GET | `/api/v1/experiment-files/{file_id}/result` | P5.2 确定性统计摘要 |
| PLANNED | DELETE | `/api/v1/experiment-files/{file_id}` | 后续文件删除 |

公开响应不包含完整 `file_hash`、`storage_key`、原始数据行或下载地址。user_id 只来自认证上下文；不存在、跨用户及 ADMIN 访问他人资源统一 404，非 PARSED 论文为 409。

## 3. P5.2 统计摘要（已实现）

- 009 将 EXPERIMENT_ANALYSIS 任务与 ExperimentFile 显式关联，并以 CHECK、普通索引和活动任务部分唯一索引收口。
- 创建前限制 `row_count × numeric_column_count <= 5,000,000`；同文件已有活动任务或结果时幂等返回。
- 后台任务重新校验 task/file/paper/user、SHA-256、file_type、row/column 和完整 columns_info；统计后再次复核 SHA-256。
- CSV/XLSX/XLS 通过公共路径型迭代器逐行提供规范值，不缓存原始行。数值列使用 Welford 和精确 median；非数值列只计数。
- stddev 为样本标准差；拒绝非有限数、计算溢出和超 JavaScript 安全范围整数。公开摘要使用 version=1 严格 Schema。
- ExperimentResult 与 SUCCEEDED 同事务提交；flush/commit 失败回滚，commit 未知重新查询，失败状态独立重试且不删除已提交结果。

## 4. P5.3a 指标交叉验证后端（已实现）

名称只按 NFKC→casefold→Unicode 字母数字过滤。每个规范名必须恰好对应一条该任务 MetricRecord 和一个数值实验列；重复论文指标、无列、重复列、空规范名均生成固定 UNVERIFIABLE。MEAN 读取 mean、MAX 读取 max，其余 checkpoint 不猜测。

差值固定为 `experiment_value - paper_value`，允许差为 `max(abs_tolerance, abs(paper_value) * rel_tolerance)`；零论文值的 relative_diff 为 null。所有输入、计算和输出由有限数与跨字段 Schema 约束。

POST 在 ExperimentResult 行锁内复核 file/result/analysis task/paper/user 和 metric task/record/source。只投影来源 id/paper_id，MetricRecord.raw_text 延迟加载；不读取 storage、数据行或来源正文。metric_comparisons 首次原子写入，同源幂等、异源 409，提交未知以新 Session 只读回查。

## 5. P5.3b 实验前端（已实现）

### 5.1 页面组件

`ExperimentDataView.vue` 位于 `frontend/src/views/`，路由 `/papers/:id/experiment`（name: `paper-experiment`，requiresAuth: true）。

### 5.2 TypeScript 类型

- 结构类型: `ExperimentColumnInfo`, `ExperimentColumnsInfo`, `ExperimentFileMetadata`, `ExperimentFileUploadResponse`, `ExperimentFileListItem`, `ExperimentFileListResponse`, `NumericStats`, `ColumnStats`, `SummaryStatsResponse`, `ComparisonItem`, `ExperimentAnalysisTaskResponse`, `ExperimentResultResponse`, `PostComparisonsRequest`, `PostComparisonsResponse`

### 5.3 API 函数

### 5.4 页面交互

- 上传区: 扩展名、非空、20MB 本地预检，防双击锁；multipart boundary 由浏览器生成；成功/重复均刷新并选中响应文件
- 文件列表: 20 条分页、radio 单选，显示文件名/类型/大小/行数/列数/上传时间
- 可信结构: 选择文件时调用详情接口显示 columns_info；详情失败可独立重试
- 分析任务: "开始分析"按钮 → createExperimentAnalysis → 3 秒轮询 → SUCCEEDED 加载结果 / FAILED 显示错误
- 统计摘要: count/mean/stddev/min/max/median 表格，非数值列 stats 显示 em dash
- 指标任务选择: 下拉仅 SUCCEEDED METRIC_EXTRACTION，按 created_at 默认最新；无任务链接指标页
- 交叉验证: 已有 metric_comparisons 直接恢复并锁定来源；否则 createComparisons → MATCH(绿)/MISMATCH(红)/UNVERIFIABLE(橙)
- 安全: 不使用 v-html/localStorage/sessionStorage，不显示 API key/token/原始后端异常
- 生命周期: 页面、文件选择及任务标识共同防止旧响应覆盖；文件/路由变化和卸载清理 timer
