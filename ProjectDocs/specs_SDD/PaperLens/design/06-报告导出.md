## 1. 模块概述

报告导出模块负责将审阅结果、指标记录和实验分析结果导出为多种格式（Markdown / PDF / DOCX），支持中英文语言选择。

## 2. 后端设计

### 2.1 报告生成服务

**核心流程:**

1. 接收导出请求（report_type, language, include_metrics, include_experiment_analysis）
2. 创建 ExportReport 记录（状态: PENDING → GENERATING）
3. 生成报告内容
   - Markdown: 直接拼接 Markdown 文本
   - PDF: 基于 Markdown 转换
   - DOCX: 基于 Markdown 转换
4. 存储导出文件（StorageBackend）
5. 更新 ExportReport 记录（状态: READY）

**关键设计:**

- 报告格式: MARKDOWN / PDF / DOCX
- 报告语言: zh / en
- 包含选项: include_metrics（是否包含指标记录）、include_experiment_analysis（是否包含实验分析）
- 进度轮询: HTTP 轮询导出进度

**API 接口:**

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 生成导出报告 | POST | /api/v1/papers/{paper_id}/exports | 创建导出任务 |
| 获取导出状态 | GET | /api/v1/exports/{export_id} | 轮询导出进度 |
| 下载报告 | GET | /api/v1/exports/{export_id}/download | 文件流下载 |

**数据模型:**

| 表名 | 说明 |
|------|------|
| export_reports | 导出报告表（report_type, status, storage_key, content_hash, file_size, error_message） |

### 2.2 Markdown 报告模板

**报告结构:**

```markdown
# {paper_title} - 审阅报告

## 论文信息
- 标题: {title}
- 文件: {filename}
- 页数: {page_count}

## 审阅结果

### {dimension} (评分: {rating}/5)
{summary}

#### 优点
- {strength_content} 查看证据：`#evidence-{id}`

#### 缺点
- {weakness_content} 查看证据：`#evidence-{id}`

#### 改进建议
- {suggestion_content} 查看证据：`#evidence-{id}`

## 总评
{overall_verdict}

## 实验指标
| 模型 | 数据集 | 指标 | 值 | 口径 |
|------|--------|------|-----|------|
| {model} | {dataset} | {metric} | {value} | {checkpoint} |

## 实验数据交叉验证
| 指标 | 论文值 | 实验值 | 偏差 | 状态 |
|------|--------|--------|------|------|
| {metric} | {paper_value} | {exp_value} | {diff} | {status} |
```

## 3. 前端设计

### 3.1 报告导出页面 (P08 ReportExportView)

**核心功能:**

- 导出配置：格式选择（Markdown / PDF / DOCX）、语言选择（中文 / 英文）、包含选项
- 生成按钮：提交导出请求
- 导出历史：历史导出列表，含状态、文件大小、下载操作
- 进度显示：生成中显示进度百分比，3 秒轮询
- 下载按钮：状态为 READY 时显示

**交互行为:**

| 交互 | 行为 |
|------|------|
| 点击"生成报告" | 调用 POST /papers/:id/exports |
| 生成中 | 3 秒轮询 GET /exports/:export_id |
| 生成完成 | 状态变为 READY，显示下载按钮 |
| 点击"下载" | 调用 GET /exports/:export_id/download |
| 生成失败 | 显示错误信息 |

## 4. 关键设计决策

| 决策 | 说明 |
|------|------|
| Markdown 优先 | Markdown 为基础格式，PDF/DOCX 通过转换生成 |
| 异步生成 | 报告生成可能耗时，使用后台任务 + HTTP 轮询 |
| content_hash | 内容哈希用于缓存，避免重复生成 |
