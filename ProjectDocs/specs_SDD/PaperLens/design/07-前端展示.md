# 前端展示模块设计

## 文档信息

| 项目 | 内容 |
|------|------|
| 模块编号 | 07 |
| 模块名称 | 前端展示 |
| 实现状态 | 部分实现（P01-P04 已实现，P05-P08 规划） |
| 关联需求 | FR-01.x, FR-02.x, FR-03.x, FR-06.x |

## 1. 模块概述

前端展示模块基于 Vue3 + TypeScript + Element Plus 构建，负责所有用户交互界面。当前已实现首页、论文上传、论文列表、论文详情四个页面，审阅结果、指标分析、实验数据、报告导出四个页面待实现。

## 2. 技术架构

### 2.1 技术栈

| 技术 | 版本 | 说明 |
|------|------|------|
| Vue3 | 3.x | 组合式 API + `<script setup>` |
| TypeScript | - | 类型安全 |
| Element Plus | - | PC 端 UI 组件库 |
| Pinia | 2.x | 状态管理 |
| Axios | - | HTTP 请求封装 |
| Vue Router | 4.x | 路由管理 |

### 2.2 项目结构

```
frontend/
├── src/
│   ├── api/              # API 请求封装
│   ├── components/       # 通用组件
│   ├── views/            # 页面视图
│   │   ├── HomeView      # 首页 (P01)
│   │   ├── UploadView    # 论文上传 (P02)
│   │   ├── PaperListView # 论文列表 (P03)
│   │   ├── PaperDetailView # 论文详情 (P04)
│   │   ├── ReviewResultView # 审阅结果 (P05, 规划)
│   │   ├── MetricAnalysisView # 指标分析 (P06, 规划)
│   │   ├── ExperimentDataView # 实验数据 (P07, 规划)
│   │   └── ReportExportView # 报告导出 (P08, 规划)
│   ├── stores/           # Pinia 状态管理
│   ├── router/           # 路由配置
│   └── utils/            # 工具函数
```

## 3. 页面设计

### 3.1 P01 首页 (HomeView) — 已实现

**核心功能:**

- 项目标题和副标题展示
- 后端健康检查状态卡（绿色正常 / 红色不可用 / 灰色检测中）
- 两个主操作入口：上传论文、论文列表

**API 依赖:**

| API | 用途 |
|-----|------|
| GET /api/v1/health | 后端健康检查 |

### 3.2 P02 论文上传 (UploadView) — 已实现

**核心功能:**

- 拖拽/选择 PDF 文件上传
- 文件类型和大小校验
- 上传进度显示
- 上传成功跳转到论文详情

**API 依赖:**

| API | 用途 |
|-----|------|
| POST /api/v1/papers/upload | 上传论文 |

### 3.3 P03 论文列表 (PaperListView) — 已实现

**核心功能:**

- 论文表格列表（标题、文件名、状态、页数、创建时间、操作）
- 状态标签颜色区分
- PROCESSING 状态自动轮询（3 秒间隔）
- 分页支持

**API 依赖:**

| API | 用途 |
|-----|------|
| GET /api/v1/papers | 获取论文列表 |

### 3.4 P04 论文详情 (PaperDetailView) — 已实现

**核心功能:**

- 元信息栏：文件名、大小、页数、状态标签
- 三 Tab 切换：章节 / 页面 / 证据
- 章节卡片：标题、类型、页码范围、文本预览
- 页面导航：上一页/下一页、页码显示、跳转输入框
- 页面内容：normalized_text_content 文本 + Evidence 高亮
- 证据列表：页码、类型、引用文本，可点击跳转高亮

**Evidence 高亮机制:**

- 基于 char_start / char_end 在 normalized_text_content 中标记
- 高亮背景色: #fff176（黄色）
- 高亮后 scrollIntoView 定位
- 降级处理: char 区间无效时显示橙色提示条

**API 依赖:**

| API | 用途 |
|-----|------|
| GET /api/v1/papers/:id | 论文详情 |
| GET /api/v1/papers/:id/sections | 章节列表 |
| GET /api/v1/papers/:id/pages/:page_number | 页面内容 |
| GET /api/v1/papers/:id/evidences | 证据列表 |

### 3.5 P05 审阅结果 (ReviewResultView) — 规划

**核心功能:**

- 审阅概览：总评分数、维度数、Finding 总数
- 维度卡片：按 dimension 分组，评分和摘要
- Finding 卡片：类型标签、内容、置信度、证据链接
- Finding 类型筛选
- 空状态：未发起审阅时显示"发起审阅"按钮

**API 依赖:**

| API | 用途 |
|-----|------|
| GET /api/v1/papers/:id/reviews | 审阅结果 |
| POST /api/v1/papers/:id/tasks | 创建审阅任务 |

### 3.6 P06 指标分析 (MetricAnalysisView) — 规划

**核心功能:**

- 筛选栏：模型名、数据集、口径下拉筛选
- 指标表格：模型名、数据集、指标名、值、口径类型、口径来源
- 行展开详情：来源证据、表格行号、证据链接
- 空状态：未提取指标时显示"提取指标"按钮

**API 依赖:**

| API | 用途 |
|-----|------|
| GET /api/v1/papers/:id/metrics | 指标记录 |
| POST /api/v1/papers/:id/tasks | 创建指标提取任务 |

### 3.7 P07 实验数据 (ExperimentDataView) — 规划

**核心功能:**

- 上传区：拖拽/选择 CSV/XLSX/XLS
- 文件列表：文件名、类型、行列数、删除操作
- 统计摘要：count/mean/std/min/max/median
- 交叉验证：MATCH(绿)/MISMATCH(红) 状态标签

**API 依赖:**

| API | 用途 |
|-----|------|
| POST /api/v1/papers/:id/experiment-files/upload | 上传实验数据 |
| GET /api/v1/papers/:id/experiment-files | 文件列表 |
| GET /api/v1/experiment-files/:file_id/result | 分析结果 |
| DELETE /api/v1/experiment-files/:file_id | 删除文件 |

### 3.8 P08 报告导出 (ReportExportView) — 规划

**核心功能:**

- 导出配置：格式选择、语言选择、包含选项
- 生成按钮：提交导出请求
- 导出历史：状态、文件大小、下载操作
- 进度显示：3 秒轮询

**API 依赖:**

| API | 用途 |
|-----|------|
| POST /api/v1/papers/:id/exports | 生成导出报告 |
| GET /api/v1/exports/:export_id | 导出状态 |
| GET /api/v1/exports/:export_id/download | 下载报告 |

## 4. 导航架构

### 4.1 路由结构

```
首页 (/)
  ├── 上传论文 (/upload)
  └── 论文列表 (/papers)
        └── 论文详情 (/papers/:id)
              ├── 章节 Tab
              ├── 页面 Tab
              ├── 证据 Tab
              ├── 审阅 (/papers/:id/review)
              ├── 指标 (/papers/:id/metrics)
              ├── 实验 (/papers/:id/experiment)
              └── 导出 (/papers/:id/export)
```

### 4.2 共享布局

P05-P08 页面共享论文详情头部和 Tab 导航栏，建议提取为 `PaperDetailLayout` 组件：

```typescript
{ path: '/papers/:id', component: PaperDetailLayout, children: [
  { path: '',          name: 'paper-detail',    component: PaperDetailContent },
  { path: 'review',    name: 'paper-review',    component: ReviewResultView },
  { path: 'metrics',   name: 'paper-metrics',   component: MetricAnalysisView },
  { path: 'experiment',name: 'paper-experiment', component: ExperimentDataView },
  { path: 'export',    name: 'paper-export',    component: ReportExportView },
]}
```

## 5. 设计规范

### 5.1 布局规范

| 项目 | 规范 |
|------|------|
| 页面最大宽度 | 960px（居中） |
| 页面内边距 | 2rem 上下，1rem 左右 |
| 主色调 | #1a1a2e（深蓝黑） |
| 卡片圆角 | 8px |
| 按钮圆角 | 6-8px |

### 5.2 状态色规范

| 状态 | 文字色 | 背景色 | 用途 |
|------|--------|--------|------|
| 正常/成功 | #2e7d32 | #e8f5e9 | 已解析、MATCH、健康 |
| 警告/进行中 | #f57c00 | #fff3e0 | 解析中、PROCESSING |
| 错误/失败 | #c62828 | #ffebee | 失败、MISMATCH、错误 |
| 高亮 | - | #fff176 | Evidence 高亮 |
| 降级 | #e65100 | #fff3e0 | 高亮降级提示 |

### 5.3 交互规范

| 场景 | 规范 |
|------|------|
| 加载状态 | 显示"加载中..."文字提示 |
| 轮询间隔 | 3 秒 |
| 错误提示 | 红色背景卡片，含重试按钮 |
