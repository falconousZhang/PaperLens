## 2. 数据表定义

### 2.1 Paper (论文主表) ✅ 已实现

| 字段名 | 数据类型 | 约束 | 说明 |

| error_message | TEXT | | 解析失败时的错误信息 |

| created_at | TIMESTAMP | NOT NULL | 创建时间 |
| updated_at | TIMESTAMP | NOT NULL | 更新时间 |


| 字段名 | 数据类型 | 约束 | 说明 |
|--------|----------|------|------|
| id | UUID | PK | 主键 |
