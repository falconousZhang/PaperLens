## 4. 核心页面设计

### 4.1 P01 首页 (HomeView)

**组件结构:**

- 标题区: 项目名 + 副标题
- 状态卡: 后端健康检查结果
- 操作按钮: 上传论文 (primary) + 论文列表 (secondary)

**数据流:**

- 页面加载 → `GET /api/v1/health` → 更新状态卡
- 点击"上传论文" → 路由跳转 `/upload`
- 点击"论文列表" → 路由跳转 `/papers`

### 4.2 P02 论文上传 (UploadView)

**组件结构:**

- 拖拽区: 虚线边框，支持 drag-drop 和点击选择
- 文件信息: 文件名和大小
- 进度条: 上传进度百分比
- 错误提示: 非 PDF / 超过 50MB
- 上传按钮

**数据流:**

- 选择/拖拽文件 → 校验类型和大小
- 点击"上传" → `POST /api/v1/papers/upload`
- 上传成功 → 路由跳转 `/papers/:id`

### 4.3 P03 论文列表 (PaperListView)

**组件结构:**

- 表格: 标题、文件名、状态、页数、创建时间、操作
- 状态标签: 解析中(橙) / 已解析(绿) / 失败(红) / 上传中(灰)
- 分页: 页码导航

**数据流:**

- 页面加载 → `GET /api/v1/papers`
- PROCESSING 状态 → 3 秒间隔轮询
- 点击"查看" → 路由跳转 `/papers/:id`

### 4.4 P04 论文详情 (PaperDetailView)

**组件结构:**

- 元信息栏: 文件名、大小、页数、状态标签
- Tab 切换: 章节 / 页面 / 证据
- 章节卡片列表
- 页面内容 + Evidence 高亮
- 证据列表

**Evidence 高亮核心逻辑:**

```typescript
function highlightEvidence(
  normalizedText: string,
  charStart: number | null,
  charEnd: number | null,
  quotedText: string
): { highlighted: string; degraded: boolean } {
  if (charStart === null || charEnd === null) {
    return { highlighted: normalizedText, degraded: true }
  }
  const extracted = normalizedText.substring(charStart, charEnd)
  if (extracted !== quotedText || charStart < 0 || charEnd > normalizedText.length) {
    return { highlighted: normalizedText, degraded: true }
  }
  const before = normalizedText.substring(0, charStart)
  const match = normalizedText.substring(charStart, charEnd)
  const after = normalizedText.substring(charEnd)
  return {
    highlighted: `${before}<mark class="evidence-highlight">${match}</mark>${after}`,
    degraded: false
  }
}
```

**数据流:**

- 页面加载 → `GET /api/v1/papers/:id` + `GET /api/v1/papers/:id/sections` + `GET /api/v1/papers/:id/evidences`
- PROCESSING 状态 → 3 秒轮询
- 切换页面 Tab → `GET /api/v1/papers/:id/pages/:page_number`
- 点击证据 → 切换到页面 Tab + 跳转页码 + 高亮
- `?evidence=` 只在当前论文已加载 Evidence 中精确匹配；未知或数组 query 显示提示

### 4.5 P05 审阅结果 (ReviewResultView) — 已实现

**组件结构:**

- 审阅概览: 总评分、维度数、Finding 总数
- 维度卡片: dimension 分组，评分和摘要
- Finding 卡片: 类型标签、内容、置信度、证据链接
- 筛选: STRENGTH / WEAKNESS / SUGGESTION
- 活动任务进度、轮询失败重试、失败/取消和成功无结果状态

**数据流:**

- 页面加载 → 并行获取 paper/tasks/reviews，并恢复最新 PENDING/RUNNING REVIEW 任务
- 点击"查看证据" → 跳转 `/papers/:id?evidence=:id`，由 PaperDetail 精确匹配并高亮
- 无审阅结果 → 显示"发起审阅"按钮 → `POST /api/v1/papers/:id/tasks`
- 审阅进行中 → 3 秒轮询 `GET /api/v1/tasks/:task_id`，活动期间禁用重复创建
- 新任务成功前继续展示上一轮成功结果；结果按最新且已有 ReviewResult 的 task_id 归组
- timer、paper id 变化和旧异步响应使用 generation 机制收口

### 4.6 P06 指标分析 (MetricAnalysisView) — 已实现

**组件结构:**

- 成功任务选择：仅显示 `SUCCEEDED` 指标任务，默认后端返回顺序中的最新项
- 筛选栏：指标名、数据集精确筛选与 Checkpoint 下拉
- 指标表格：模型、数据集、显示值/存储值、Checkpoint、来源、原文和创建时间
- 来源：单 Evidence 使用论文详情 query 深链；单表格显示 ID/0-based 行号；异常结构降级

**数据流:**

- 页面加载 → 并行读取 paper/tasks，只在选定成功任务后用 `task_id` 查询 metrics
- 活动任务 → 每 3 秒轮询；运行中保留成功历史，终态停止；创建和活动期间按钮锁定
- 筛选/分页/任务切换 → 后端查询，独立 request id 防止旧响应覆盖
- 点击"查看证据" → `/papers/:id?evidence=:evidence_id` 并精确高亮
- 路由 paper id 变化/卸载 → generation 失效旧异步响应并清理 timer
- 文本安全 → 所有后端文本使用 Vue 插值，`raw_text` 通过原生 details 展开

### 4.7 P07 实验数据 (ExperimentDataView) — 规划

**组件结构:**

- 上传区: 拖拽/选择 CSV/XLSX/XLS
- 文件列表: 文件名、类型、行列数、删除
- 统计摘要表格: count/mean/std/min/max/median
- 交叉验证: MATCH(绿)/MISMATCH(红)

**数据流:**

- 上传文件 → `POST /api/v1/papers/:id/experiment-files/upload`
- 页面加载 → `GET /api/v1/papers/:id/experiment-files`
- 选择文件 → `GET /api/v1/experiment-files/:file_id/result`

### 4.8 P08 报告导出 (ReportExportView) — 规划

**组件结构:**

- 导出配置: 格式选择、语言选择、包含选项
- 生成按钮
- 导出历史: 状态、文件大小、下载操作

**数据流:**

- 点击"生成报告" → `POST /api/v1/papers/:id/exports`
- 生成中 → 3 秒轮询 `GET /api/v1/exports/:export_id`
- 点击"下载" → `GET /api/v1/exports/:export_id/download`
