## 1. 认证边界

- access：15 分钟 JWT，固定 HS256，必含 sub/sid/jti/typ/iat/nbf/exp/iss/aud。
- refresh：至少 256 bit 不透明随机值，只通过 `paperlens_refresh` HttpOnly/SameSite=Lax cookie 传输；生产 HTTPS 使用 Secure。
- reset：15 分钟不透明随机值、单次消费；refresh/reset 数据库只保存 SHA-256 摘要。
- access 鉴权必须同时通过 JWT、AuthSession 和 User 当前状态；不能只信任 token 内角色或用户状态。
- 前端只在 Pinia 内存保存 access/UserPublic，不使用 localStorage/sessionStorage 保存凭据。

## 2. 会话状态机

```text
ACTIVE --refresh--> REPLACED(old revoked + replaced_by) + ACTIVE(new)
ACTIVE --logout/password/status--> REVOKED
REPLACED token replay --detect--> whole family REVOKED
ACTIVE --expires--> EXPIRED/REVOKED
```

同一 refresh 行通过 PostgreSQL `FOR UPDATE` 串行化；并发刷新最多一次成功。再次使用已轮换 token 必须在事务内撤销同 family 新会话。

## 3. 数据与删除策略

- User 允许 `demo-user` legacy disabled 占位的 password_hash 为空；ACTIVE 注册用户必须有 Argon2id hash。
- AuthSession 和 PasswordResetToken 的 token_hash 唯一，并为用户、family、hash、过期时间建立索引。
- Paper、AnalysisTask、ExperimentFile、ExportReport 到 User 均为 RESTRICT，禁止删除用户时级联清空论文和结果。
- 004 为初始认证迁移；005 在不回滚开发库的前提下纠正约束和索引，最终 head 为 `005_auth_security_corrections`。

## 4. API

公开：register、login、refresh、forgot-password、reset-password。

需 Bearer：logout、logout-all、GET/PATCH me、change-password，以及全部论文/Evidence/task/review 路由。认证 401 含 `WWW-Authenticate: Bearer`；已认证但角色不足为 403。

register/login/refresh 返回 access、expires_in 和 UserPublic，并设置/轮换 refresh cookie；任何响应都不含 password/session/token hash。forgot 始终返回同一 202 文案。

## 5. 密码与锁定

- 15～128 个可打印 Unicode code point，允许空格，不 trim、不截断、不强制组合规则。
- 拒绝内置常见弱口令、项目名和邮箱本身；尚未接入完整泄露口令语料库。
- 不存在、禁用、锁定、密码错误均走 Argon2 dummy/真实验证并返回相同 401。
- 失败计数用用户行锁保护；当前只有账号级数据库锁定，分布式 IP 限流待部署层。

## 6. RBAC 与 legacy

- USER/ADMIN 角色以数据库当前值为准；ADMIN 不自动绕过普通资源所有权。
- 无默认管理员。显式执行 `python -m paperlens.cli admin-bootstrap --user-id <UUID4> --reason <text>`，仅零 ACTIVE ADMIN 时允许。
- 首次引导同事务撤销目标旧 session 并写入 ADMIN_BOOTSTRAPPED 不可变审计；不再提供 email 模糊匹配或 demo-user 归属迁移入口。
- 完整用户管理、账号启停、管理员内容操作、审计日志和管理控制台属于 P7。

## 7. 通知与华为云

PasswordResetNotifier 可注入；默认 Null 实现不联网、不记录 token。自动测试使用 capture fake。生产适配器尚未实现，后续优先评估华为云通知/邮件能力。华为云 IAM 不代替 PaperLens 产品账号。
