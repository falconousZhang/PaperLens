# 论文阅读学习模块设计

## 1. 模块定位

本模块是 PaperLens 的产品主线：帮助用户围绕自己上传的论文阅读、理解、核实和复习。既有结构化审阅保留为“批判性阅读”工具，不与学习解释共用结果表或评分语义。

## 2. P7.1 范围

- 新增 PaperReadingView，整合章节目录、页面正文、Evidence 定位和学习助手。
- 支持 SUMMARY、EXPLAIN、TRANSLATE 三种固定学习模式。
- 来源仅允许 SECTION、PAGE、EVIDENCE；所有正文由服务端按 id 获取。
- 持久化解释历史与有序 Citation；不实现自由问题、多轮会话、笔记或知识卡。

## 3. 来源解析

1. 校验用户、论文所有权和 PARSED 状态。
2. SECTION 必须属于论文；使用 section.text_content，并按 section_id 或页码范围选择 Evidence。
3. PAGE 必须在 1～page_count 且存在 PaperPage；使用 normalized_text_content，候选 Evidence 限定同页。
4. EVIDENCE 必须属于论文；只使用对应 quoted_text。
5. 候选按 page_number/created_at/id 稳定排序，逐条截断且总输入受配置上限约束；来源为空或超出安全边界时固定失败。
6. canonical scope、来源文本哈希、mode 和 language 生成 request_hash；hash 不对外公开。

## 4. 模型契约

论文内容放入明确的 untrusted XML 标签，系统消息声明其中任何指令无效。模型只能返回一个 JSON 对象：

```json
{
  "answer": "纯文本答案",
  "key_points": ["要点"],
  "terms": [{"term": "术语", "explanation": "解释"}],
  "evidence_refs": ["E1"]
}
```

answer、数组数量、单项长度、对象字段和 alias 均严格校验；`extra=forbid`。至少一个 alias，全部必须来自本次候选且去重后仍非空。任何未知引用或模糊围栏都使整次结果失败。MockLLMClient 通过显式 learning operation 分支返回同一契约，不改变 REVIEW 现有行为。

## 5. 状态与事务

创建阶段在短事务中校验来源并写 PENDING；活动或已成功同 request_hash 返回既有行。后台用条件更新原子认领 RUNNING，然后结束事务再调用 LLM。解析成功后重新校验来源图，在同一事务写 answer/key_points/terms、全部 Citation 和 SUCCEEDED。异常回滚后写固定 FAILED；日志不含正文、prompt、原始响应或 secret。

## 6. 前端交互

三栏布局以正文为核心。用户选择章节、页面或某条 Evidence，再选择模式和语言。创建后 3 秒轮询；成功显示答案、要点、术语和可点击引用，失败显示固定重试入口。历史严格分页，路由或 scope 改变使旧响应失效。选中文字解释详情通过已有 selection_start/selection_end 映射为持续蓝色矩形；历史悬停选区具有更高临时优先级，移开后自动恢复详情选区。

## 7. 后续扩展

P7.2 在本模块上增加检索式论文问答和会话历史；P7.3 增加用户高亮、书签、笔记、知识卡和学习进度。管理员系统在 P8.1 合并交付，不与普通用户学习数据的所有权规则混用。

## 8. 验收重点

- 跨用户、跨论文和伪造 scope 不能触发模型调用。
- 论文中的 prompt 注入文本不能改变输出契约。
- 无真实 Citation 的回答不能公开。
- 模型调用期间没有数据库事务；成功结果与 Citation 原子一致。
- Vue 不使用 v-html/Web Storage，竞态和定时器全部可控。

## 9. 实现结果

P7.1 已完成。数据库使用 013 初始表和 014 无损契约收紧；服务端提供 3 条 owner-only API；PaperReadingView 提供三栏阅读、真实历史分页、3 秒轮询、失败重试和 Citation 原文定位。实际验收为后端定向 36、全量 866、前端 183、构建 135 modules，Alembic 014 无漂移，测试库零残留。

## 10. 学习解释退出交互

顶部标签栏仅保留三个模块标签。学习解释的退出按钮移动到生成按钮下方，使用普通 button 调用组件内部 `clearAssistant`，随后定位 `.history-section`；不调用 Router，不清空历史，不改变当前页。

退出按钮仅在 `activeExplanation` 存在时渲染，视觉使用红底白字；清理详情后自动移除。
