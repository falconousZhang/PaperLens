# 15. 个人学习沉淀与论文库

## 15.1 概述

P7.3 实现用户个人学习数据的闭环：论文库组织（阅读状态/收藏/文集）、阅读进度追踪、高亮标注、书签、笔记和知识卡。所有数据按 user_id 隔离，不调用 LLM/Embedding。

## 15.2 数据模型

### 15.2.1 新增枚举

| 枚举 | 值 |
|------|-----|
| ReadingStatus | TO_READ, READING, COMPLETED, ARCHIVED |
| HighlightColor | YELLOW, GREEN, BLUE, PINK |
| AnchorType | PAPER, PAGE, HIGHLIGHT |
| MasteryStatus | NEW, LEARNING, MASTERED |

### 15.2.2 paper_library_entries

复合主键 (user_id, paper_id)。LEFT JOIN 论文库列表，无 entry 时返回默认值。reading_status CHECK、completed_at 与 COMPLETED 联动 CHECK。

### 15.2.3 paper_highlights

UQ (user_id, paper_id, page_number, char_start, char_end) 防重复。source_hash SHA256 校验。服务端从 PaperPage.normalized_text_content 派生 quoted_text。

### 15.2.4 paper_bookmarks

UQ (user_id, paper_id, page_number) 防同页重复。重复创建返回 200 + duplicate=true。

### 15.2.5 paper_notes

CHECK ck_note_anchor_exclusive：PAPER 锚点无 page_number/highlight_id；PAGE 锚点有 page_number 无 highlight_id；HIGHLIGHT 锚点有 highlight_id 无 page_number。highlight_id FK → paper_highlights.id (RESTRICT)。

### 15.2.6 paper_knowledge_cards

CHECK ck_card_source_exclusive：source_note_id 与 source_highlight_id 互斥（含双 null）。source_note_id FK → paper_notes.id (RESTRICT)，source_highlight_id FK → paper_highlights.id (RESTRICT)。mastery_status 变化时更新 last_reviewed_at。

## 15.3 API 设计

### 15.3.1 论文库 (library router)

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /library/papers | 论文库列表（支持 reading_status/favorite/collection_name/keyword 筛选） |
| PATCH | /papers/{id}/library-entry | 更新阅读状态/收藏/文集 |
| PATCH | /papers/{id}/reading-progress | 更新阅读进度（page_number） |

### 15.3.2 学习记录 (personal_learning router)

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /papers/{id}/highlights | 创建高亮（服务端派生 quoted_text/source_hash） |
| GET | /papers/{id}/highlights | 列出高亮（支持 page_number 筛选） |
| DELETE | /highlights/{id} | 删除高亮（被引用时 409） |
| POST | /papers/{id}/bookmarks | 创建书签（重复返回 200） |
| GET | /papers/{id}/bookmarks | 列出书签 |
| DELETE | /bookmarks/{id} | 删除书签 |
| POST | /papers/{id}/notes | 创建笔记（锚点校验） |
| GET | /papers/{id}/notes | 列出笔记（支持 anchor_type/page_number/highlight_id 筛选） |
| PATCH | /notes/{id} | 更新笔记内容 |
| DELETE | /notes/{id} | 删除笔记（被引用时 409） |
| POST | /papers/{id}/knowledge-cards | 创建知识卡（来源互斥） |
| GET | /papers/{id}/knowledge-cards | 列出知识卡（支持 mastery_status/archived 筛选） |
| PATCH | /knowledge-cards/{id} | 更新知识卡（front/back/mastery_status/archived） |
| DELETE | /knowledge-cards/{id} | 删除知识卡 |

## 15.4 服务端关键逻辑

1. **论文库列表**：LEFT JOIN subquery，无 entry 时返回 TO_READ/favorite=false，不为列表读取而写库
2. **高亮服务端派生**：从 PaperPage 加载文本，校验 char 范围，派生 quoted_text 和 source_hash，不信任客户端
3. **引用删除 409**：高亮被 Note/Card 引用时 409；Note 被 Card 引用时 409
4. **阅读进度**：TO_READ→READING 自动变；COMPLETED/ARCHIVED 不被自动改写；furthest_page 只增不减
5. **COMPLETED 联动**：reading_status=COMPLETED 时服务端写 completed_at；非 COMPLETED 时清空
6. **collection_name 空白转 null**：PATCH 时空白字符串转为 null 存储

## 15.5 前端设计

### 15.5.1 论文库 (PaperListView)

- 搜索框（keyword 搜索标题/文件名）
- 状态筛选（TO_READ/READING/COMPLETED/ARCHIVED）
- 收藏筛选
- 进度条（progress_percent）
- 收藏按钮（★/☆）
- 高亮/笔记/卡片计数列
- 状态循环按钮

### 15.5.2 学习记录标签 (PaperReadingView)

- 面板新增第三个标签"学习记录"
- 四个子标签：高亮/书签/笔记/知识卡
- 高亮：新建高亮（Selection/Range offset 计算）、颜色选择、删除
- 书签：收藏当前页、删除
- 笔记：新建笔记（选择锚点类型）、删除
- 知识卡：新建（可选来源）、mastery 状态切换、归档、删除
- 翻页后串行调用 reading-progress API
