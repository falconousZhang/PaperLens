## 1. 范围

P8.4 是既定计划最后一个开发轮次。它不新增业务页面、公开 API、数据库表或迁移，交付华为云 OBS 存储适配以及 ECS + RDS + OBS + MaaS + ELB/WAF 的生产部署、备份恢复和安全基线。真实云资源创建、域名证书、Secret 注入和计费调用仍由用户在部署时完成。

## 2. OBS 存储设计

`StorageBackend` 新增 `materialize(storage_key)` 上下文管理器。LocalStorage 返回已校验本地路径；OBSStorage 下载到权限为 0600 的唯一临时文件，并在成功、失败或调用方异常后统一删除。`exports`、`export_service` 和 `experiment_analysis_service` 已迁移到该接口，OBS 不再返回离开上下文即失效的路径。

OBSStorage 使用 `esdk-obs-python==3.26.2`：

- ECS Agency 使用 `security_provider_policy="ECS"`，ENV 兜底使用 SecretStr AK/SK/Token。
- 客户端启用长连接、单一 10～60 秒超时、有限重试/重定向和 CA 校验。
- 上传显式使用 `PutObjectHeader`、私有 ACL 与 `SseKmsHeader`；SSE-OBS 为 AES256，SSE-KMS 为 kms + key id。
- save/get/delete 均只接受 2xx；SDK 异常、临时文件异常和非 2xx 统一映射为固定错误，不回显 endpoint、bucket、key、路径或原始异常。
- key 拒绝空值、绝对路径、反斜杠、空段、`.`/`..`、控制字符和超长值；单例工厂使用锁保护并由 lifespan 关闭。

## 3. 生产配置

`PAPERLENS_ENV=production` 时 fail-closed：

- 禁止 debug、本地存储、不安全 cookie、弱/占位 JWT、HTTP 或非华为 OBS/MaaS 地址。
- RDS 只接受 PostgreSQL DSN，拒绝 localhost/loopback，且必须唯一指定 `sslmode=verify-full` 和 `sslrootcert`。
- LLM 与 Embedding 必须选择 Huawei MaaS 并通过 Secret 文件提供 Key。
- OBS ENV 模式必须提供非空 AK/SK；KMS 模式必须提供 key id。
- 可信代理 CIDR 必须为受限网段，不能为空或全网；生产关闭 Swagger、ReDoc 和 OpenAPI JSON。

## 4. Secret 与容器生命周期

`entrypoint.prod.sh` 在 `serve` 和 `migrate` 两种命令前统一读取数据库、JWT、LLM、Embedding 及可选 OBS 的 `*_FILE`，缺失或空文件立即失败，不打印内容。数据库 DSN 不写入 Compose environment，RDS CA 作为只读 Secret 挂载。

后端生产镜像使用 Python 3.13，与项目语法基线一致，只安装 `requirements.prod.txt`，不包含 pytest、测试目录、`.env` 或数据目录。前后端均为非 root；Compose 使用只读根文件系统、`/tmp` tmpfs、`cap_drop: ALL`、no-new-privileges、PID/CPU/内存限制和健康检查。

## 5. 网络与 Nginx

唯一宿主机入口是前端 8080，绑定 ECS 私网 IP，由安全组仅允许 ELB 访问；backend:8000 只在固定 `172.30.0.0/24` Compose 私网暴露。Nginx 监听非特权 8080，pid 和全部临时目录位于 `/tmp`，可在非 root + read-only 下运行。

Nginx 追加而非清空 X-Forwarded-For；应用只在直接 peer 和后续代理命中显式可信 CIDR 时解析代理链。响应包含 CSP、HSTS、X-Frame-Options、X-Content-Type-Options 和 Referrer-Policy，关闭目录浏览与 server token。

## 6. 部署与恢复

`deploy/huawei/` 包含生产 Compose、ECS Agency 默认配置、OBS ENV 可选覆盖、Nginx、非敏感环境模板、部署指南和备份恢复手册。镜像必须使用不可变版本；先执行 Compose 静态校验和 migrate，迁移失败不得启动业务容器。

RDS 自动备份、PITR 和发布前手工备份的保留策略取决于已确认 RPO/RTO；文档不承诺未经演练的固定时长。恢复到新实例并只读核验后人工切换。OBS 使用私有桶、SSE、版本控制和经确认的生命周期规则；应用回滚优先切换上一镜像，结构不兼容时从备份恢复新 RDS，不执行破坏性自动 downgrade。

## 8. 轻量单机 ECS 档案

### 8.1 适用边界

该档案只服务于低成本实习项目演示。前端、后端和 PostgreSQL 共用一台 4 GiB ECS；论文文件与数据库使用本地命名卷，不提供跨可用区容灾。现有正式华为云档案继续作为域名、HTTPS、RDS、OBS、ELB 和 SWR 上线方案。

### 8.2 网络与数据流

`EIP:80 -> nginx:8080 -> backend:8000 -> postgres:5432`。只有 Nginx 映射主机端口，后两级仅加入 `172.30.0.0/24` 私有桥接网络。Nginx 对 API 文档入口返回 404，转发客户端地址和 `$scheme`；HTTP 档案不发送 HSTS。

### 8.3 配置与持久化

`deploy/huawei/.env.single` 由服务器本地生成，权限固定为 600，不进入版本库或镜像。数据库密码限制为 URL 安全随机值；JWT Secret 独立生成；MaaS Key 必须先轮换再通过无回显输入写入。`postgres_data` 和 `backend_data` 分别保存关系数据与论文文件，任何维护操作均不得使用 `down -v`。

### 8.4 资源控制

PostgreSQL 上限 640 MiB，迁移容器 512 MiB，后端 1536 MiB，Nginx 256 MiB；ECS 配置 2 GiB Swap 作为构建和峰值保护。首次启动先等待数据库健康并运行 Alembic，迁移成功后才启动后端，后端健康后再启动前端。
