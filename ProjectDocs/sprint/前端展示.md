## 开发进度

### 已完成

- 论文上传页面（P02）：拖拽/选择上传、文件类型校验（.pdf）、大小限制（50MB）、上传进度条、成功后跳转论文详情
- 论文列表页面（P03）：表格展示论文列表、状态标签颜色（解析中/已解析/失败/上传中）、PROCESSING 状态 3 秒轮询、组件卸载清除定时器、分页展示
- 论文详情页面（P04）：
  - 章节/页面/证据三 Tab 切换
  - Evidence 高亮跳转（基于 char_start / char_end）
  - 降级处理（char 区间无效时显示提示）
  - PROCESSING 状态 3 秒轮询
  - 请求去重（request id 防止陈旧响应覆盖）
  - stopPolling() / startPolling() 抽取
  - evidenceDegraded 统一检查（null / 越界 / mismatch）
- 前端项目初始化（Vue3 + TypeScript + Vite + Pinia + Axios）🔴 PLANNED: Element Plus 未安装
- 前端首页 + 健康检查调用 + 后端不可用提示

## 问题与风险

### 已解决

| 问题 | 描述 | 解决方案 | 解决日期 |
|------|------|----------|----------|
| 翻页丢请求 | pageLoading 逻辑导致并发翻页丢失请求 | 移除 pageLoading，使用 request id 防陈旧响应覆盖 | 2026-07-13 |
| Evidence 降级无提示 | char 区间无效时前端无反馈 | evidenceDegraded 统一检查 null / 越界 / mismatch | 2026-07-13 |
| 轮询定时器泄漏 | 组件卸载时定时器未清除 | stopPolling() 抽取，组件卸载时调用 | 2026-07-13 |

### 遗留问题

| 问题 | 描述 | 影响 | 优先级 |
|------|------|------|--------|
| 审阅结果页面未开发 | 依赖后端审阅生成 API（P3）完成 | 用户无法查看审阅结果 | 高（依赖 P3） |
| 指标分析页面未开发 | 依赖后端指标提取 API（P4）完成 | 用户无法查看指标数据 | 中（依赖 P4） |

### 存疑事项

- 前端页面开发顺序：P05（审阅结果）→ P06（指标分析）→ P07（实验数据）→ P08（报告导出），需与后端开发进度对齐
- 审阅结果页面是否需要支持实时流式展示（当前设计为轮询模式）
