# Sprint：实验数据上传与解析

## 范围

P5.1 只交付 CSV、XLSX、XLS 的安全上传、确定性结构解析、文件列表和详情 API。统计摘要、ExperimentResult、实验分析任务、指标交叉验证、P07 前端和报告导出不在本 Sprint。

## 设计约束

- 上传文件按固定块写入随机服务端临时文件，实际字节限制为 1～20MB；所有路径关闭 UploadFile 并清理临时文件。
- 解析器只接收临时文件路径和已确认的 `ExperimentFileType`，不访问数据库、存储、LLM、Embedding 或网络。
- CSV 只接受 UTF-8、UTF-8 BOM、GB18030 和逗号/分号/Tab；分隔符判断必须唯一。
- XLSX 在 openpyxl 解析前完成 ZIP entry、解压大小、压缩比、路径、加密、宏、外链、嵌入对象和公式检查。
- `columns_info` 为 version=1 的严格对象，不保存样本值或数据行；dtype 仅为 integer、float、boolean、datetime、string、empty。
- 同一 user/paper/SHA-256 幂等；并发由数据库唯一约束收口，新建 201、重复 200，最终一行一对象。
- storage.save、flush、commit 任一步失败均回滚并补偿未归属对象；日志不得包含内容、用户文件名、本机路径、SQL 参数或 secret。
- 完整 SHA-256 仅保留在数据库内部，不进入公开 API。

## API

- `POST /api/v1/papers/{paper_id}/experiment-files/upload`
- `GET /api/v1/papers/{paper_id}/experiment-files?page=1&page_size=20`
- `GET /api/v1/experiment-files/{file_id}`

不存在或跨用户统一 404；仅当前用户自己的 PARSED 论文可上传；非 PARSED 返回 409；类型或 magic 不符返回 415；实际字节超限返回 413；内容/结构不可解析返回 422；内部上传失败返回固定安全 500。
