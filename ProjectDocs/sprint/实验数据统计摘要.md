# P5.2 实验数据确定性统计摘要后端闭环

## 状态：已完成

## 目标

在 P5.1 CSV/XLSX/XLS 安全上传与可信结构解析基础上，实现实验文件的确定性统计任务、ExperimentResult 原子写入和结果查询 API。只完成"已上传实验文件 → 后台统计任务 → 可查询严格统计摘要"的后端闭环。

## 已实现

### 迁移 009

- `analysis_tasks` 新增 nullable `experiment_file_id` UUID FK → `experiment_files.id` ON DELETE RESTRICT
- CHECK 约束 `ck_experiment_analysis_has_file_id`：EXPERIMENT_ANALYSIS 当且仅当 experiment_file_id 非空
- 普通索引 `idx_task_experiment_file_id`
- 部分唯一索引 `uq_active_experiment_task_per_user_file(user_id, experiment_file_id)`，仅覆盖 PENDING/RUNNING 的 EXPERIMENT_ANALYSIS
- 迁移前只读检查开发库是否存在 EXPERIMENT_ANALYSIS 历史任务
- upgrade/downgrade 可逆

### 统计服务 (`experiment_statistics.py`)

- Welford 稳定算法计算 mean/stddev（样本标准差 ddof=1，count<2 时 null）
- 精确中位数（偶数样本取中间两值均值）
- 数值安全：拒绝 NaN/Infinity、超 JS 安全整数、计算溢出
- `summary_stats` version=1 严格 JSON，按原列顺序
- integer/float 列有 stats（mean/stddev/min/max/median），其余 dtype stats 为 null
- boolean 不按 0/1 参与数值统计
- 空列 count=0/null_count=row_count/stats=null
- CSV/XLSX/XLS 通过公共路径型迭代器逐行读取，不构造全行列表；只保存数值列紧凑数组用于精确 median

### 分析服务 (`experiment_analysis_service.py`)

- 任务创建：用户隔离、论文状态检查、数值单元格数前置限制（413 ANALYSIS_TOO_LARGE）
- 后台执行：原子 PENDING→RUNNING→SUCCEEDED/FAILED
- 文件完整性复核：重算 SHA-256、重新执行 P5.1 magic/结构解析，不一致按文件损坏安全失败
- 成功时同一事务插入唯一 ExperimentResult（只写 summary_stats）
- 失败时 rollback 结果，任务设 FAILED，error_message 只能是固定安全分类
- 幂等：同一文件已有结果或活动任务时返回既有资源
- 并发创建依赖 009 唯一索引收口
- 不依赖 LLM/Embedding client
- 并发唯一约束失败后重新查询并返回胜者 200；任务认领、成功提交和失败提交均处理 commit 结果未知
- 计算前后复核 SHA-256，完整比较 columns_info；失败补偿不删除可能已经提交的结果

### API

- `POST /api/v1/experiment-files/{file_id}/analysis`（201 新建/200 幂等）
- `GET /api/v1/experiment-files/{file_id}/result`（200/404）
- 无 token 401、跨用户/ADMIN 他人 404、非 PARSED 409

- `max_experiment_analysis_numeric_cells`：默认 5,000,000，合法范围 1～10,000,000
