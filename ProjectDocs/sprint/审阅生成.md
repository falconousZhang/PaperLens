## Codex 独立审查修正

码道初版 102 项测试可通过，但独立审查发现并直接修正：结果批次与 SUCCEEDED 状态分两次提交、UUID 路径未使用 UUID4、LLM 测试替换依赖全局可变单例、审阅查询未在 SQL 层绑定任务用户、请求 schema 过度宽松、Prompt Evidence/Title 标签可被原文闭合、重复 Evidence alias 可产生重复关联，以及自定义 Pydantic 校验错误无法 JSON 序列化而返回 500。P3.1 文档中大量规划态和测试计数也已校准。码道还将两个 Codex 提示词文件还原到 HEAD，违反了任务范围；这些文件由 Codex 在验收收口阶段恢复。
