## Codex 审查纠正

2. 修复 refresh 重放未撤销 family、replaced_by 未写入、并发刷新竞态和 access 不查 session。
3. 修复禁用/锁定枚举、reset token 日志泄漏、logout 无认证、cookie Secure 硬编码和 401 缺少 WWW-Authenticate。
4. token 从 localStorage 改为纯内存；bootstrap 改为 refresh cookie；补齐 single-flight 与外站 redirect 防护。
5. 将用户业务资源外键从 CASCADE 改为 RESTRICT，并补 token_hash 唯一/有效期索引。
