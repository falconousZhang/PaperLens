## 开发进度

### 已完成

- PDF 文件上传接口（multipart/form-data、类型校验、大小限制 50MB、路径穿越防护、SHA-256 哈希计算与存储，去重 📋 PLANNED）
- 论文列表与详情接口（分页查询、状态过滤、级联删除、UUID 校验）
- 论文上传前端页面（P02：拖拽/选择上传、文件校验、进度显示）
- 论文列表前端页面（P03：表格展示、状态标签、PROCESSING 轮询）
- PDF 页面文本提取（PyMuPDF + pdfplumber、normalized_text_content、页面尺寸）
- 章节结构识别（正则匹配标题模式、section_type 枚举）
- 表格提取与存储（pdfplumber、structured_data JSONB、SAVEPOINT 降级）
- 文本分块（按章节/段落分块、chunk_index / char_count / page_numbers、预留 embedding_id）
- 后台任务框架（FastAPI BackgroundTasks）
- 本地存储服务（LocalStorage，storage_key 格式 papers/{uuid}/source.pdf）
- 统一错误响应（含 details 字段、_safe_error_message() 安全错误映射）
- 数据库迁移脚本（003_normalized_and_error）

## 问题与风险

### 已解决

| 问题 | 描述 | 解决方案 | 解决日期 |
|------|------|----------|----------|
| 表格 bbox 非法 | page_number=0 的表格触发 PostgreSQL CheckConstraint | 使用 SAVEPOINT 包裹每个表格，失败仅 rollback SAVEPOINT 不影响外层事务 | 2026-07-13 |
| UploadFile 资源泄漏 | 上传失败时 UploadFile 未关闭 | 单一 close 出口 + try/finally 确保关闭 | 2026-07-13 |
| 测试隔离不足 | 测试污染开发数据库 | database.py 延迟初始化 + configure_engine() + 数据库名守卫 | 2026-07-13 |
| 扫描型 PDF 处理 | 扫描型 PDF 无可提取文本 | 抛出 OCR_NOT_SUPPORTED 异常，解析状态设为 FAILED | 2026-07-13 |
