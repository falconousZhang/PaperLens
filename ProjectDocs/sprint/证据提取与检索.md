## 问题与风险

### 已解决

| 问题 | 描述 | 解决方案 | 解决日期 |
|------|------|----------|----------|
| Evidence char 区间不匹配 | normalized_text_content 与 bbox 文本不一致 | char_start / char_end 设为 null 降级，前端显示提示 | 2026-07-13 |
| 前端翻页丢请求 | pageLoading 逻辑导致并发翻页时丢失请求 | 移除 pageLoading，使用 request id 防陈旧响应覆盖 | 2026-07-13 |
| Evidence 降级提示 | char 区间无效时前端无反馈 | evidenceDegraded 统一检查 null / 越界 / mismatch | 2026-07-13 |

### 遗留问题

| 问题 | 描述 | 影响 | 优先级 |
|------|------|------|--------|
| FAISS 向量索引未实现 | 向量索引服务仅预留接口，未实际构建 | 无法进行语义检索，审阅生成依赖此功能 | 高 |

### 存疑事项

- Embedding 模型选型：需确定使用哪个 Embedding 模型（本地部署 vs API 调用）
- FAISS 索引持久化：需确定存储位置（本地文件 vs OBS）
- FAISS → Milvus 迁移路径：当前设计预留了迁移可能性，需评估迁移成本
