| language | VARCHAR(2) | NOT NULL DEFAULT 'zh' | 报告语言：zh / en |
| include_metrics | BOOLEAN | NOT NULL DEFAULT true | 是否包含指标记录 |

| source_snapshot | JSONB | | 创建时审阅/指标/实验结果快照 |
| source_hash | VARCHAR(64) | | source_snapshot 规范 JSON 的 SHA-256；历史骨架行为空 |
| user_id | VARCHAR(128) | NOT NULL | 所属用户 |
| created_at | TIMESTAMP | NOT NULL | 创建时间 |
| completed_at | TIMESTAMP | | 完成时间 |

**P6 最终 CHECK 约束（010 + 011 + 012）**：
- `ck_export_report_type_values`：report_type 只允许 MARKDOWN / PDF / DOCX
- `ck_export_language_values`：language 只允许 zh / en
- `ck_export_status_values`：status 只允许 PENDING / GENERATING / READY / FAILED
- source_snapshot/source_hash 同空同非空，source_hash/content_hash 为 64 位小写十六进制
- source_snapshot 非空行允许 MARKDOWN/PDF/DOCX；非 FAILED 状态在建行时已有 content_hash
- READY 必须有 storage_key/file_size/completed_at；FAILED 必须有 error_message/completed_at；其余状态不得声明存储对象

**P6 来源感知部分唯一索引**：
- `uq_active_export_source`：UNIQUE(user_id, paper_id, report_type, language, include_metrics, include_experiment_analysis, source_hash, content_hash) WHERE source_hash/content_hash 非空且 status IN ('PENDING','GENERATING','READY')

CREATE UNIQUE INDEX uq_active_experiment_task_per_user_file ON analysis_tasks(user_id, experiment_file_id) WHERE task_type='EXPERIMENT_ANALYSIS' AND status IN ('PENDING','RUNNING');

### 3.2 唯一约束与复合主键

| 表 | 类型 | 名称/定义 | 列 |
|----|------|-----------|----|
| paper_pages | UniqueConstraint | uq_paper_page | paper_id, page_number |
| paper_chunks | UniqueConstraint | uq_paper_chunk | paper_id, chunk_index |
| paper_tables | UniqueConstraint | uq_paper_table | paper_id, page_number, table_index |
