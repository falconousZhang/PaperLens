## 1. 项目概览

### 1.1 项目信息

- **项目名称**：PaperLens
- **项目周期**：9 个阶段（P0-P8）
- **技术栈**：FastAPI + SQLAlchemy + Alembic（后端）、Vue3 + TypeScript（前端）、PostgreSQL（数据库）
- **当前进度**：P5.1 已完成 Codex 独立验收；CSV/XLSX/XLS 安全上传、结构解析和元数据 API 可用，下一阶段为 P5.2 确定性统计摘要
