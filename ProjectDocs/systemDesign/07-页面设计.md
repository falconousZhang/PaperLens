## 页面原型总览

| 编号 | 页面名称 | 路由 | 实现状态 | 功能概述 |
|------|----------|------|----------|----------|
| P01 | 首页 | `/` | 已实现 | 项目入口，后端健康检查，快捷导航 |
| P02 | 论文上传 | `/upload` | 已实现 | PDF 拖拽/选择上传，进度显示 |
| P03 | 论文列表 | `/papers` | 已实现 | 论文表格列表，状态轮询，分页 |
| P04 | 论文详情 | `/papers/:id` | 已实现 | 章节/页面/证据三 Tab，Evidence 高亮跳转 |
| P05 | 批判性阅读（原审阅结果） | `/papers/:id/review` | ✅ CURRENT | 按 task 归组展示审阅 Finding，任务交互与 Evidence 追溯 |
| P06 | 指标分析 | `/papers/:id/metrics` | ✅ CURRENT | 指标任务交互、历史结果隔离、筛选分页与来源追溯 |
| P07 | 实验数据 | `/papers/:id/experiment` | ✅ CURRENT | P5.3b 前端已实现：上传、文件列表、分析轮询、统计摘要、指标交叉验证 |
| P08 | 报告导出 | `/papers/:id/export` | ✅ CURRENT | 多格式导出配置，进度轮询，下载 |
| P09 | 论文阅读学习工作台 | `/papers/:id/read` | ✅ P7.1 COMPLETED | 章节/页面阅读、Evidence 定位、总结/解释/翻译和学习历史 |

| 高亮降级 | char 区间无效或与 quoted_text 不匹配时，显示降级提示 |
| 轮询失败 | 显示错误信息和重试按钮 |

### 5.2 设计说明

| 元素 | 说明 |
|------|------|
| 审阅概览 | 总评、维度数、Finding 总数和 overall_verdict |
| 维度卡片 | 按 dimension 分组，每个维度显示评分和摘要 |
| Finding 卡片 | 类型标签（STRENGTH 绿/WEAKNESS 红/SUGGESTION 蓝）、内容、置信度 |
| 结果归组 | 优先展示 tasks 倒序中最新且已有结果的 task_id，不混合历史任务 |
| 证据链接 | 每个 evidence_id 独立跳转到 PaperDetail，并在同论文 Evidence 列表精确匹配后高亮 |
| 状态区 | 空状态、活动任务进度、失败/取消、成功无结果、加载或轮询错误均有明确恢复入口 |

### 5.3 交互行为

| 交互 | 行为 |
|------|------|
| 页面加载 | 并行加载论文、tasks 和 reviews；恢复最新 PENDING/RUNNING REVIEW 任务 |
| 点击"查看证据" | 跳转 `/papers/:id?evidence=:evidence_id`，由 PaperDetail 切到页面 Tab 并高亮 |
| 无审阅结果 | 显示"发起审阅"按钮，点击调用 `POST /api/v1/papers/:id/tasks` |
| 审阅进行中 | 显示限制在 0～100 的进度条，3 秒轮询任务状态；活动任务期间禁止重复创建 |
| 重新审阅 | 新任务成功前继续显示上一轮成功结果，并单独显示进度或失败状态 |
| 轮询失败 | 停止 timer，保留任务状态并提供“重试轮询/重新加载”；始终最多一个 timer |
| Finding 类型筛选 | 可按 STRENGTH / WEAKNESS / SUGGESTION 筛选 |

### 5.4 API 依赖

| API | 用途 |
|-----|------|
| `GET /api/v1/papers/:id/reviews` | 获取审阅结果 |
| `GET /api/v1/papers/:id/tasks` | 获取任务历史并恢复活动任务 |
| `POST /api/v1/papers/:id/tasks` | 创建审阅任务（task_type=REVIEW） |
| `GET /api/v1/tasks/:task_id` | 轮询任务进度 |

## 6. P06 指标分析 (MetricAnalysisView)

### 6.1 页面布局（线框图）

```
+==================================================================+
|  Attention Is All You Need                                        |
|  文件: attention.pdf | 页数: 12 | 已解析                          |
+==================================================================+
|  [章节]  [页面]  [证据]  [审阅]  [指标]  [实验]  [导出]           |
+==================================================================+
|                                                                    |
|  历史任务: [最近成功任务 ▼]                                      |
|  筛选: [指标名]  [数据集]  [Checkpoint ▼]                         |
|                                                                    |
|  +--------------------------------------------------------------+  |
|  | 模型       | 数据集    | 指标 | 显示值 | Checkpoint | 来源      |  |
|  |------------|----------|------|--------|------------|-----------|  |
|  | BERT-base  | SQuAD    | F1   | 83.1%  | BEST      | 查看证据  |  |
|  | BERT-large | SQuAD    | loss | 0.234  | FINAL     | 表格/行号 |  |
|  +--------------------------------------------------------------+  |
|                                                                    |
|  +--- 来源原文 -------------------------------------------------+  |
|  | 存储值: 0.831；raw_text 可展开查看                           |  |
|  | Evidence: [查看证据 >]；表格: table_id / 0-based row_index   |  |
|  +--------------------------------------------------------------+  |
|                                                                    |
|  返回列表                                                          |
+==================================================================+
```

### 6.2 设计说明

| 元素 | 说明 |
|------|------|
| 历史任务 | 仅列出成功的指标任务，默认选择后端顺序中的最新成功任务，查询始终携带 `task_id` |
| 筛选栏 | 指标名、数据集精确筛选和 Checkpoint 下拉，筛选由后端分页查询完成 |
| 指标表格 | 模型、数据集、指标名、显示值/存储值、Checkpoint、来源、原文和创建时间 |
| 口径标签 | FINAL/MAX/MEAN/BEST/LAST/UNKNOWN 均有中文文本与稳定样式 |
| 来源追溯 | 单一 Evidence 生成论文详情深链；单一表格来源显示 `table_id` 与 0-based `row_index`；双来源或无来源安全降级 |
| 原文 | `raw_text` 仅以文本插值输出，可展开且长文本换行，不使用 `v-html` |
| 空状态 | 未提取指标时显示"提取指标"按钮 |

### 6.3 交互行为

| 交互 | 行为 |
|------|------|
| 页面加载 | 并行读取论文与任务；只处理 `METRIC_EXTRACTION`，选择最新成功任务后携带 `task_id` 查询指标 |
| 筛选/分页/任务变更 | 重置必要分页并重新请求；独立请求序号阻止旧响应覆盖新目标 |
| 点击"查看证据" | 跳转 `{name:'paper-detail', query:{evidence:evidence_id}}` 并由论文详情高亮 |
| 无指标数据 | 显示"提取指标"按钮，调用 `POST /api/v1/papers/:id/tasks`（task_type=METRIC_EXTRACTION） |
| 提取进行中 | 恢复或创建活动任务后每 3 秒轮询，保留上一轮成功结果并锁定重复创建 |
| 任务终态 | SUCCEEDED 刷新任务并切换到新 `task_id`；FAILED/CANCELLED 保留旧结果并允许显式重试 |
| 生命周期 | 论文路由变化、连续请求和组件卸载均使旧异步结果失效并清理 timer |

### 6.4 API 依赖

| API | 用途 |
|-----|------|
| `GET /api/v1/papers/:id/metrics` | 获取指标记录 |
| `GET /api/v1/papers/:id/tasks` | 获取任务历史并恢复活动指标任务 |
| `GET /api/v1/tasks/:task_id` | 轮询指标任务状态 |
| `POST /api/v1/papers/:id/tasks` | 创建指标提取任务 |

### 7.2 设计说明

## P09-C 学习记录标签页（P7.3 PaperReadingView 扩展）

PaperReadingView 在"学习助手"区域新增"学习记录"标签页，包含四个子标签：

```text
┌────────────── 学习记录 ──────────────┐
│ [高亮] [书签] [笔记] [知识卡]         │
│ ──────────────────────────────────── │
│ 高亮列表：                            │
│ 第 3 页  "Our model achieves..."      │
│          黄色  [删除]                 │
│ 第 5 页  "The transformer..."         │
│          绿色  [删除]                 │
│ [新建高亮] - 选中正文后触发           │
└──────────────────────────────────────┘
```

- **高亮子标签**：按页码分组展示，颜色标记，可删除（被引用时提示 409）
- **书签子标签**：按页码排序，显示标签，可删除
- **笔记子标签**：按创建时间排序，显示锚定类型和内容，可编辑/删除
- **知识卡子标签**：按 mastery_status 分组，显示正/背面，可编辑掌握状态/归档/删除

正文区选中文字后弹出高亮创建浮层（颜色选择 + 确认），前端计算 char_start/char_end 偏移并提交。阅读进度在翻页时串行 PATCH 更新，保证同一论文同一时刻最多一个在途请求。
