# PaperLens 备份、恢复与回滚手册

实施方：码道（CodeArts）  
适用版本：P8.4

## 1. 恢复目标

RPO、RTO 必须由项目负责人根据业务要求确定，并在华为云当前套餐能力下通过演练验证。本手册不承诺固定时长。每次演练记录实际备份时间、恢复耗时、数据时间点和核验结果。

## 2. RDS PostgreSQL

- 启用自动备份，并根据已确认的 RPO 设置保留期和时间点恢复能力。
- 每次包含数据库迁移的发布前创建手工备份，等待备份成功后再发布。
- RDS 使用私网和 `sslmode=verify-full`，恢复实例同样不得开放公网入口。

恢复步骤：

1. 在 RDS 控制台选择目标备份或时间点，恢复到新实例，不覆盖当前生产实例。
2. 只读核对 Alembic 版本、关键表计数、管理员审计链和抽样业务数据。
3. 更新受控的 `database_url` Secret 指向新实例，先验证 `/health/ready`，再人工切换流量。
4. 保留旧实例直至观察期结束；任何清理都需单独审批。

## 3. OBS

- 私有桶启用版本控制；SSE-OBS 或 SSE-KMS 覆盖所有新对象。
- 生命周期规则根据实际保留要求清理历史版本和未完成分段上传，规则启用前先评估误删风险。
- 应用删除对象不等于立即清除历史版本；恢复时在 OBS 控制台选择指定历史版本并复制为当前版本。
- 不提供、也不运行全桶删除脚本。

## 4. 应用回滚

1. 将 `.env.production` 中前后端镜像改为上一已验收的不可变版本。
2. 执行 Compose 配置校验并拉取该版本。
3. 如果数据库结构向后兼容，重建 backend/frontend 并执行健康检查与最小业务冒烟。
4. 如果结构不兼容，停止发布，按第 2 节恢复到新 RDS 实例后再切换。

不得在没有备份与恢复验证的情况下直接执行破坏性 Alembic downgrade。

## 5. 定期演练

建议按项目确认的周期执行：恢复 RDS 到隔离实例、核对关键数据、恢复一个 OBS 历史版本、启动上一应用镜像、记录实测 RPO/RTO 和问题。临时资源的删除属于独立运维动作，需确认目标后执行。
