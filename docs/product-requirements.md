# PaperLens 产品需求文档

> 产品定位（2026-07-15 校正）：PaperLens 是面向个人研究者与学生的 AI 论文阅读学习助手。核心价值是帮助用户读懂、定位、解释、复习论文；“审阅”仅作为批判性阅读模式，不再作为产品主线。

## 1. 用户角色

| 角色 | 描述 |
|------|------|
| 学习者（Learner） | 阅读课程论文、教材型论文或入门论文，需要翻译、解释概念并形成学习笔记的学生 |
| 研究者（Researcher） | 需要快速理解论文方法、实验、结论和证据，并持续积累个人知识库的科研人员 |
| 批判性读者（Critical Reader） | 需要从合理性、新颖性、完整性等维度检查论文论证质量的高级用户 |
| 平台管理员（Administrator） | 负责用户、权限、论文任务、系统运行状态和审计记录管理的运维人员 |

## 2. 核心使用场景

### 场景一：论文阅读工作台

用户上传 PDF 后，在同一工作台中按章节或页面阅读正文，使用目录导航，并从 AI 输出的引用直接回到对应 Evidence 和页码。

### 场景二：辅助理解

用户针对当前章节、页面或原文证据发起中文/英文总结、通俗解释或翻译。系统只使用服务端确认的论文内容，回答必须引用真实 Evidence。

### 场景三：基于论文的问答学习

用户围绕当前论文提问，系统检索相关 Evidence 后回答；证据不足时明确说明“不足以从本文确认”，不把外部常识伪装成论文结论。

### 场景四：个人学习沉淀

用户保存高亮、书签和笔记，将核心概念、方法、结论整理为知识卡或复习清单，并记录阅读进度。

### 场景五：批判性阅读与实验理解

用户可选用现有结构化审阅、指标提取、实验数据统计和交叉验证能力，检查论文论证、理解实验口径并核对结果。它们是高级阅读工具，不是产品入口或唯一目标。

### 场景六：学习成果导出

用户将论文摘要、解释、笔记、知识卡，以及可选的批判性阅读与实验分析结果导出为 Markdown / PDF / DOCX 学习报告。

### 场景七：账号与管理员系统

用户通过完整账号体系访问自己的论文与学习数据；管理员通过独立后台管理用户、角色、账号状态和运行信息，并记录敏感管理操作审计。

## 3. 核心痛点

1. **论文读不懂**：陌生术语、复杂方法和公式会打断阅读，用户需要与当前上下文紧密结合的解释。
2. **长文容易迷失**：章节、页面、结论和证据分散，读者难以建立全文结构和当前位置感。
3. **AI 回答难以核实**：通用问答容易脱离论文原文，用户无法快速判断回答依据。
4. **读完难以沉淀**：高亮、笔记、概念和结论缺少统一组织，后续复习成本高。
5. **实验理解成本高**：指标口径、表格和实验文件难以快速核对，容易误读论文结论。

## 5. 非目标功能

| 项目 | 说明 |
|------|------|
| 论文自动投稿 | 不涉及投稿流程 |
| 代写论文或作业 | 不生成可冒充用户原创的整篇论文或课程作业 |
| 学术搜索引擎 | 当前只处理用户上传的论文，不构建全网检索引擎 |
| 无依据的开放域问答 | 问答必须以当前论文为边界；外部知识必须明确标识，MVP 不联网补充 |
| 论文查重 | 不提供查重服务 |
| 模型训练平台 | 只调用推理接口，不提供训练平台 |
| 扫描型 PDF / OCR | MVP 只支持包含可提取文本的 PDF |

## 6. 约束与原则

1. **阅读优先**：首页、论文详情和路线图首先服务“读懂论文”，批判性审阅是可选模式。
2. **回答可追溯**：总结、解释、翻译、问答和批判性结论必须绑定服务端确认的 Evidence；引用无效则整次结果失败，不公开半可信结果。
3. **论文内容不可信**：论文正文、标题和用户问题均作为不可信输入包裹，不能覆盖系统指令。
4. **证据不足要诚实**：无法从论文确认时必须明确降级，不得伪造引用或把常识写成论文结论。
5. **大模型不直接计算统计数据**：所有 mean、max、std 等由确定性 Python 代码计算。
6. **用户数据隔离**：论文、学习记录、审阅、实验和报告都按真实 user_id 隔离；ADMIN 不通过普通业务 API 绕过所有权。
7. **LLM 可替换且华为云优先**：默认离线 Mock，可配置 HuaweiMaaSLLMClient；自动测试不得访问真实网络或读取密钥。
8. **完整账号与管理员系统仍是交付要求**：产品方向校正不取消用户登录注册、权限和管理员后台，只调整开发优先级。
9. **不增加既定轮数**：P7.1～P8.4 通过重排和合并完成学习核心、管理员系统与发布验收。

P7.1 已交付 3 条 learning API 和受保护的 `/papers/:id/read`；P7.2 已交付当前论文多轮问答、5 条 owner-only API、Evidence 检索引用、双分页、失败重试和证据不足降级；P7.3 已交付高亮、书签、笔记、知识卡、论文库与学习进度。下一固定轮次为 P8.1 完整管理员系统。
