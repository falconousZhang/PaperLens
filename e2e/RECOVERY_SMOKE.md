# P8.2 隔离核心烟测

本清单只用于独立验收环境，不得连接开发库、真实华为云模型或用户文件。

## 安全前置条件

- 数据库名称必须为 `paperlens_test`。
- LLM 与 Embedding 必须使用 Mock。
- 后端存储目录必须是一次性测试目录。
- 普通用户与管理员均使用临时测试账号。

## 唯一代表性流程

1. 注册并登录一个普通用户，上传一篇最小可解析 PDF。
2. 等待论文进入 `PARSED`，发起一次审阅任务。
3. 在任务仍为活动状态时停止测试后端，等待超过恢复阈值后重新启动。
4. 重新进入审阅页，确认页面自动读取服务端状态，不允许重复提交活动任务；缺少可重放参数时应进入固定安全 `FAILED`，并允许从原入口重新发起。
5. 使用隔离环境中的管理员账号进入管理后台，确认看到的任务状态与普通用户页面一致，且看不到论文正文、模型内容、令牌或存储路径。
6. 注销两个测试账号，确认前端没有残留轮询请求。

## 通过标准

- 刷新和重启后不会永久停留在“处理中”。
- 同一资源最多一个在途轮询请求，页面切换或注销后轮询停止。
- 用户端与管理员端状态一致。
- 失败信息为固定公开文案，不包含内部异常。
- 验收过程中不访问开发库、真实 MaaS 或真实用户文件。
